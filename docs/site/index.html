Layout: German (QWERTZ) Target: Corne v4 CI: GitHub Actions

German Layout By Default

The GUI opens with the German QWERTZ keymap selected. Recording keys while German is active now resolves visible letters like Y and Z to the HID keycodes a German OS layout expects.

Corne v4 Capacity Notes

Layers, macro slots, tap dance entries, combos, key overrides, and alt-repeat entries are firmware limits. The Corne guide shows the `config.h` and `rules.mk` settings to raise them before flashing.

Quantum Reference

The app includes an About-menu reference generated from Vial's actual Quantum keycode table, including QMK IDs, aliases, and plain-language behavior.

Builds And Testing
